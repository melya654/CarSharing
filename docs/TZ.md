# Технічне завдання: AUTOM, сайт прокату авто

Варіант 17 «Автосалон / прокат авто». Студент: Мельник Андрій, група 31-КН.
Основна сутність: автомобіль. Обов'язкова функція: фільтр за кількома параметрами і порівняння авто.

## 1. Аналіз конкурентів

| Сайт | Сильні сторони | Слабкі сторони |
|---|---|---|
| Getaround | Бронювання з телефона за кілька кроків; авто видно на мапі | Англійською, багато реєстрації до того, як побачиш ціну; немає порівняння авто |
| Zipcar | Зрозуміла схема «як це працює»; погодинний тариф | Фільтри прості, порівняти дві машини поруч не можна; сайт важкий на мобільному |
| Місцеві прокати авто в Івано-Франківську (сайти-візитки) | Ціна за добу одразу видно; можна подзвонити | Немає фільтрів, усі авто одним списком; форма замовлення без перевірки даних, часто не адаптовано під телефон |

Висновок: моя ніша це простий український сайт, де можна відфільтрувати авто одразу за кількома параметрами, поставити 2–3 машини поруч і швидко залишити заявку.

## 2. Мета і аудиторія

Мета сайту: дати людині за 2–3 хвилини вибрати авто і залишити заявку на оренду.

Цільова аудиторія: мешканці міста 20–45 років без власного авто, люди у відрядженні, сім'ї, яким авто треба на відпустку, малий бізнес.

Ключові сценарії:
1. Знайти авто за фільтрами (кузов, пальне, КПП, ціна, тільки вільні).
2. Порівняти до 3 авто в таблиці і вибрати найкраще.
3. Відкрити сторінку авто і забронювати через форму.

## 3. Карта сайту

- Головна `/`
  - Каталог `/cars`
  - Деталі авто `/cars/:id`
  - Порівняння `/compare`
  - Бронювання і контакти `/contacts`
  - Адмінка `/admin` (працює з API)
  - 404 (будь-яка інша адреса)

## 4. Функціональні вимоги

1. Каталог завантажує список авто з API (`GET /api/cars`) або з `cars.json`, якщо сервера немає.
2. Фільтр одночасно за кузовом, пальним, КПП, максимальною ціною і наявністю.
3. Пошук за маркою чи моделлю з затримкою 300 мс (debounce).
4. Сортування: за ціною в обидва боки, за роком, за потужністю.
5. Додавання до 3 авто в порівняння; вибір зберігається в localStorage.
6. Таблиця порівняння з підсвіткою найкращого значення в кожному рядку.
7. Сторінка деталей авто з усіма характеристиками і кнопкою «Забронювати».
8. Форма бронювання з перевіркою на клієнті і на сервері; авто підставляється з адреси `?car=id`.
9. Модальне вікно після успішної заявки, закривається по Esc і кліку поза ним.
10. Перемикач світлої і темної теми, тема зберігається.
11. Адмінка: додати і видалити авто через API.
12. Сторінка 404 для неіснуючих адрес.

## 5. Нефункціональні вимоги

- Адаптивність mobile-first: коректно на 360, 768 і 1280 px.
- Швидкодія: Lighthouse Performance ≥ 90 на мобільному.
- Доступність: WCAG AA (контраст ≥ 4.5:1), робота з клавіатури, skip-link, aria-атрибути.
- SEO: унікальні title і description для кожної сторінки, sitemap.xml, robots.txt, JSON-LD.
- Працює офлайн хоча б частково (PWA, service worker).

## 6. Стек

- Дизайн: Figma
- Клієнт: React 19 + Vite, React Router, чистий CSS з custom properties (токени з Figma)
- Сервер: Node.js + Express 5, cors, dotenv, дані в JSON-файлі (fs/promises)
- Тести: Vitest + React Testing Library
- Деплой: Vercel, автодеплой з гілки main
- Git + GitHub
